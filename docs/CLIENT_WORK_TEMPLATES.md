## Delivery checklist

### Before work

- [ ] Executed scope and authorized start are recorded.
- [ ] Stakeholders, approvers, communications path, and windows are known.
- [ ] Access is least privilege, named, tested, time-bounded, and inventoried.
- [ ] Secrets are absent from email, tickets, source control, logs, deliverables.
- [ ] Baseline evidence, backup responsibility, and rollback decision are recorded.
- [ ] Acceptance tests and evidence format are agreed.

### During work

- [ ] Actions, observations, decisions, and scope changes are timestamped.
- [ ] Changes have authorization, pre-checks, rollback, and validation.
- [ ] Client data is minimized and kept only in approved locations.
- [ ] Risks/blockers avoid unsupported outcome or timing claims.
- [ ] Deliverables receive factual, security, and usability review.

### Handoff and acceptance

- [ ] Deliverables match scope and contain no secrets/unintended client data.
- [ ] Tests ran in the agreed environment; pass/fail/not-tested are separate.
- [ ] Limitations, monitoring, rollback/recovery, and owner actions are explicit.
- [ ] Client acceptance or punch-list decision is written and attributable.
- [ ] Billing owner receives only approved milestone/acceptance evidence.
